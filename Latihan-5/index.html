Padding, Border & Box-sizing

Catatan belajar CSS layouting: lapisan di dalam kotak dan cara menghitung ukurannya.

1. Padding

Jarak antara isi (content) dan border. Padding berada di dalam kotak, jadi ikut terwarnai background. Pada contoh, kotak putih = content, area oranye = padding.

Masalah nyata: width 100% + padding

Kotak merah-muda memakai width: 100% dan padding: 20px di dalam parent 300px.

content-box: keluar dari parent

  box-sizing: border-box;   /* taruh di paling atas CSS */
}

4. Latihan

Ketiga kotak berukuran 600 x 200 dengan box-sizing: border-box, jadi ukuran tetap walaupun padding dan border berbeda. Yang berubah hanya ukuran area isinya.

5. Kesimpulan

  • Padding adalah jarak di dalam border. Ikut terwarnai background, tidak boleh negatif, tidak bisa auto.
  • Border adalah garis tepi: ketebalan, jenis garis, warna. Bisa diatur per sisi.
  • Secara default padding dan border menambah ukuran kotak (content-box).
  • Dengan border-box, width sudah mencakup padding dan border, jadi ukuran lebih mudah diprediksi.
  • Tulis * { box-sizing: border-box; } di paling atas CSS.
