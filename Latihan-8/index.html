Clearfix

Catatan belajar CSS layouting: cara membuat parent mau membungkus elemen yang di-float.

1. Masalahnya Apa?

Bayangkan parent sebagai pagar dan elemen di dalamnya sebagai hewan ternak. Pagar otomatis menyesuaikan tingginya dengan hewan yang ada di dalam.

Elemen yang diberi float seperti hewan yang melompat keluar dari alur normal. Pagar menganggap isinya kosong, jadi tingginya menciut jadi nol dan hewannya terlihat berdiri di luar pagar.

tanpa perbaikan 
.parent { border: 2px solid red; }
.mini   { float: left; width: 50px; height: 50px; }

Yang terlihat: parent hanya berupa garis tipis (dua border yang menempel), padahal tiga kotak ada di dalamnya. Latar belakang parent juga tidak terlihat. Inilah masalah yang diselesaikan oleh clearfix.

2. Solusi 1: Elemen Kosong (Cara Lama)

Tambahkan elemen kosong di akhir parent dan beri clear: both. Elemen itu menolak berdampingan dengan float, jadi turun ke bawahnya dan parent ikut memanjang sampai ke situ.

elemen kosong + clear 
<div class="parent">
  <div class="mini"></div>
  <div class="mini"></div>
  <div class="clear"></div>   <!-- elemen kosong -->
</div>

.clear { clear: both; }

Kekurangan: menambah elemen HTML yang tidak punya arti, hanya demi tampilan.

3. Solusi 2: Overflow pada Parent

Beri overflow: auto atau overflow: hidden pada parent. Parent yang punya aturan overflow otomatis membungkus isinya, termasuk float.

overflow: auto 
.parent { overflow: auto; }

Kelebihan: hanya satu baris CSS.
Hati-hati: hidden memotong isi yang keluar dari parent, dan auto bisa memunculkan scrollbar yang tidak diinginkan.

4. Solusi 3: Clearfix (Paling Populer)

Ini versi rapi dari cara elemen kosong: elemen kosongnya dibuat lewat CSS memakai ::after, jadi HTML tetap bersih. Cukup tambahkan class clearfix ke parent.

class clearfix 
.clearfix::after {
  content: "";
  display: block;
  clear: both;
}
<div class="parent clearfix">
  ...elemen yang di-float...
</div>

Arti tiap baris

BarisFungsinya
::afterMembuat elemen bayangan di akhir isi parent (tidak ada di HTML)
content: ""Wajib ada. Tanpa ini elemen bayangan tidak dibuat. Isinya kosong
display: blockMenjadikannya elemen blok supaya bisa di-clear
clear: bothTurun di bawah semua float, sehingga parent ikut memanjang sampai ke sini

Nama class clearfix bebas, tetapi ini nama yang paling umum. Sekali ditulis di CSS, class ini bisa dipakai di banyak parent.

5. Solusi 4: display: flow-root (Cara Modern)

Property yang dibuat khusus untuk masalah ini. Cukup satu baris dan tidak punya efek samping seperti overflow.

display: flow-root 
.parent { display: flow-root; }

6. Perbandingan Cara

Rekomendasi: pakai display: flow-root untuk project baru. Kenali clearfix karena masih sangat sering muncul di kode lama dan tutorial.

8. Kesalahan Umum

  • Lupa content: "". Tanpa ini clearfix tidak bekerja sama sekali.
  • Memasang clearfix di elemen yang di-float, bukan di parent-nya. Class harus ada di parent.
  • Memakai overflow: hidden lalu bingung kenapa ada konten yang terpotong.
  • Mengakali dengan margin besar supaya tidak tertimpa. Itu hanya menutupi gejalanya, bukan memperbaikinya.

9. Kesimpulan

  • Parent yang semua isinya float akan menciut jadi tinggi nol.
  • Penyebabnya: float keluar dari alur normal, jadi parent menganggap isinya kosong.
  • Ada empat cara memperbaikinya: elemen kosong, overflow, clearfix, dan flow-root.
  • Clearfix memakai ::after dengan content: "", display: block, dan clear: both.
  • Untuk project baru, display: flow-root adalah pilihan paling bersih.
