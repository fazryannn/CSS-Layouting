Box Model

Catatan belajar CSS layouting: setiap elemen HTML adalah sebuah kotak dengan 4 lapisan.

1. Empat Lapisan Kotak

Dari dalam ke luar: content, padding, border, lalu margin.

2. Padding

Jarak antara isi dan border. Padding berada di dalam kotak, jadi ikut terwarnai oleh background.

padding: 0
Teks menempel di tepi
padding: 20px
Teks punya ruang napas

3. Border

Garis tepi kotak. Ditulis dalam 3 bagian: ketebalan, jenis garis, warna. 

border: 2px solid red;
solid
Garis penuh
dashed

dotted
Garis titik
double
Garis ganda

4. Margin

Jarak antar elemen. Margin berada di luar border dan selalu transparan (tidak ikut terwarnai background).

Margin collapse

Margin vertikal yang bertemu akan menyatu. Kotak A punya margin-bottom: 30px dan kotak B punya margin-top: 30px, tetapi jaraknya tetap 30px, bukan 60px (yang terbesar yang dipakai).

Kotak A (margin-bottom 30px)
Kotak B (margin-top 30px)

margin: 0 auto

Menengahkan elemen block secara horizontal. Syaratnya elemen harus punya width atau max-width.

width 200px, margin 0 auto

Ingat: margin boleh bernilai negatif (misalnya margin-top: -10px), padding tidak boleh.

5. Cara Menulis Singkat (Shorthand)

padding dan margin bisa ditulis dengan 1 sampai 4 nilai. Urutan 4 nilai: atas, kanan, bawah, kiri (searah jarum jam).

padding: 10px
Semua sisi
padding: 10px 30px
Atas-bawah, kiri-kanan
padding: 5px 10px 20px
Atas, kiri-kanan, bawah
padding: 5px 10px 15px 30px
Atas, kanan, bawah, kiri
margin-top: 20px;           /* satu sisi saja */
padding-left: 15px;
border-bottom: 2px solid black;

6. Menghitung Ukuran Total

Default-nya (content-box), width hanya menghitung content. Dengan border-box, padding dan border sudah termasuk.

content-box: total 250px
200 + padding 40 + border 10
border-box: total 200px
Tetap 200px
* {
  box-sizing: border-box;
}

Tip: tekan F12, klik elemen, lalu lihat diagram box model berwarna di tab Computed.

Ringkasan

  • Setiap elemen adalah kotak: content, padding, border, margin.
  • Padding mengatur jarak di dalam, margin mengatur jarak di luar.
  • Shorthand 4 nilai: atas, kanan, bawah, kiri.
  • Pakai box-sizing: border-box supaya hitungan ukuran mudah.
  • margin: 0 auto menengahkan elemen block yang punya lebar.
  • Margin vertikal bisa menyatu, yang dipakai adalah yang terbesar.
