Position

Catatan belajar CSS layouting: mengatur posisi elemen dengan position, top, right, bottom, left, dan z-index.

1. Apa itu Position?

position menentukan cara sebuah elemen diposisikan di halaman. Setelah diberi position selain static, elemen bisa digeser memakai top, right, bottom, dan left.

NilaiPosisinya mengacu keRuang aslinya
staticAlur normal (default)Tetap
relativePosisi semula elemen itu sendiriTetap ada
absoluteParent terdekat yang punya positionHilang
fixedLayar (viewport)Hilang
stickyRelative dulu, lalu menempel saat di-scrollTetap ada

Ingat: top, right, bottom, left, dan z-index hanya berfungsi pada elemen yang position-nya bukan static.

2. Static

Nilai default semua elemen kalau position tidak ditulis. Elemen mengikuti alur normal, dan top, left, dst. diabaikan.

position: static; top: 50px; left: 30px

Kotak kuning tidak bergeser, walaupun diberi top dan left.

3. Relative

  • Elemen bergerak relatif terhadap posisi semulanya.
  • Ruang aslinya tetap ada, jadi elemen lain tidak ikut bergeser.
  • top: 0 dan left: 0 berarti tidak berubah posisi.
top: 50px; left: 30px
top: 0; left: 0

Pada contoh kiri, kotak kuning turun 50px dan geser 30px ke kanan, sehingga menutupi sebagian kotak ungu. Kotak ungu tidak naik mengisi tempat kuning, karena ruang asal kuning masih dianggap terpakai.

Positif dan negatif

PenulisanArah gerak
top: 20pxTurun 20px
bottom: 20pxNaik 20px
left: 20pxGeser ke kanan 20px
right: 20pxGeser ke kiri 20px

Nilai tersebut mendorong elemen menjauhi sisi yang disebut. Nilai negatif membalik arahnya.

4. Absolute

  • Elemen keluar dari alur normal, ruang aslinya hilang.
  • Posisinya mengacu ke parent terdekat yang punya position (bukan static).
  • Kalau tidak ada parent seperti itu, mengacu ke halaman (elemen paling luar).
parent: relative, anak: absolute
A (normal)
B
C (normal)
D
.induk { position: relative; }          /* jadi acuan */
.badge { position: absolute;
         top: 8px; right: 8px; }        /* 8px dari sudut kanan atas induk */

Kotak B dan D absolute, jadi tidak memakan ruang: C langsung menempel di bawah A. B menempel di sudut kanan atas induk dan D di sudut kiri bawah.

Pola yang paling sering dipakai: beri parent position: relative (tanpa digeser), lalu anaknya position: absolute. Cocok untuk badge, label di atas gambar, atau tombol tutup di pojok kartu.

5. Fixed

  • Mengacu ke layar (viewport), bukan ke parent.
  • Posisinya tidak berubah saat halaman di-scroll.
  • Ruang aslinya hilang, seperti absolute.
.tombol-atas {
  position: fixed;
  bottom: 20px;
  right: 20px;
}

Contohnya ada di halaman ini: tombol "Ke atas" di pojok kanan bawah. Scroll ke mana pun, tombolnya tetap di tempat. Cocok untuk navbar yang selalu terlihat dan tombol kembali ke atas.

6. Sticky

Gabungan relative dan fixed: elemen berada di tempat normalnya, lalu menempel di posisi yang ditentukan saat di-scroll melewatinya. Wajib memakai top (atau sisi lain) agar tahu kapan menempel.

7. Z-index

Elemen yang bertumpuk bisa diatur urutan tumpukannya dengan z-index. Angka lebih besar berada di atas. Hanya berlaku untuk elemen yang position-nya bukan static.

tanpa z-index
merah z-index: 3

Tanpa z-index, elemen yang ditulis belakangan di HTML berada paling atas (ungu). Dengan z-index: 3, kotak merah naik ke paling atas.

8. Kesalahan Umum dan Kesimpulan

Kesalahan umum

  • Memakai top/left pada elemen static, hasilnya tidak ada efek.
  • Lupa memberi position: relative pada parent, sehingga absolute mengacu ke halaman.
  • Memakai sticky tanpa top, jadi tidak pernah menempel.
  • Memakai z-index pada elemen static, hasilnya tidak ada efek.

Kesimpulan

  • static adalah default dan mengabaikan top, right, bottom, left.
  • relative bergeser dari posisi semula, ruang asalnya tetap.
  • absolute mengacu ke parent terdekat yang berposisi, ruang asalnya hilang.
  • fixed mengacu ke layar dan tidak ikut scroll.
  • sticky menempel saat di-scroll melewati batas top.
  • z-index mengatur urutan tumpukan elemen berposisi.
