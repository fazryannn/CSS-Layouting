Dimensi & Overflow

Catatan belajar CSS layouting: ukuran kotak dan apa yang terjadi kalau isinya kelebihan.

1. Width & Height

width mengatur lebar dan height mengatur tinggi. Keduanya hanya berlaku di elemen block dan inline-block. Elemen inline (misalnya span) mengabaikannya.

SatuanArtinyaContoh
pxPiksel, ukuran tetapwidth: 300px
%Persen dari ukuran parentwidth: 50%
vw / vhPersen dari lebar / tinggi layarheight: 100vh
em / remRelatif terhadap ukuran fontwidth: 20rem
autoDitentukan otomatis (default)width: auto

Contoh

width 200px, height 100px
Hello World
width: 50% dari parent
50%
inline vs inline-block inline inline-block

Ingat: height: 50% sering tidak berhasil karena parent-nya belum punya tinggi yang jelas. Persen tinggi butuh acuan.

2. Min & Max

min-width, max-width, min-height, dan max-height memberi batas ukuran supaya layout fleksibel.

max-width: lebar mengikuti parent, tapi ada batasnya

width: 100%; max-width: 300px;

Coba kecilkan jendela browser: kotak ini menyusut. Saat jendela lebar, kotak berhenti di 300px.

min-height: tinggi minimal, boleh tumbuh

Isi sedikit, tinggi tetap 100px.

Pola yang sering dipakai

img {
  max-width: 100%;  /* gambar tidak pernah melebihi parent */
  height: auto;     /* proporsi tetap */
}

.container {
  max-width: 800px;
  margin: 0 auto;   /* di tengah halaman */
}

3. Box-sizing

Secara default (content-box), width hanya menghitung isi. Padding dan border ditambahkan di luarnya. Dengan border-box, padding dan border sudah termasuk.

content-box: total 250px
width 200 + padding 40 + border 10
border-box: total 200px
width 200 sudah termasuk semuanya
* {
  box-sizing: border-box;  /* taruh di paling atas CSS */
}

Tip: buka DevTools (F12), klik elemennya, dan lihat diagram ukuran di tab Computed.

7. Ringkasan

  • width/height hanya berlaku di block dan inline-block.
  • min- dan max- memberi batas supaya layout fleksibel.
  • box-sizing: border-box membuat padding dan border ikut dihitung.
  • Overflow baru muncul kalau kotak punya ukuran tetap.
  • auto adalah pilihan overflow paling rapi, scrollbar muncul hanya kalau perlu.
  • hidden memotong isi, jadi hati-hati agar tidak ada konten penting yang hilang.
