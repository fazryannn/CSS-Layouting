CSS Reset

Catatan belajar CSS layouting: menyamakan titik awal tampilan di semua browser.

1. Apa itu CSS Reset?

Setiap browser punya stylesheet bawaan (user agent stylesheet). Karena itu HTML tanpa CSS pun sudah punya tampilan: judul besar dan tebal, paragraf berjarak, list berbullet, link biru bergaris bawah.

Masalahnya, bawaan ini sedikit berbeda antar browser, dan sering mengganggu saat kita ingin mengatur layout sendiri. CSS Reset adalah sekumpulan aturan yang menghapus gaya bawaan itu, supaya semua browser mulai dari titik yang sama.

ElemenGaya bawaan browser
bodymargin 8px
h1 - h6Ukuran besar, tebal, punya margin atas-bawah
pmargin atas-bawah 1em
ul, olpadding kiri 40px, ada bullet atau nomor
aBiru dan bergaris bawah
strong, emTebal dan miring

Yang perlu diperhatikan

  • Setelah reset, judul sama besar dengan paragraf dan tidak tebal lagi.
  • Semua jarak (margin dan padding) hilang, jadi kotak hitam, judul, dan paragraf menempel.
  • List kehilangan bullet, dan strong tidak tebal lagi.
  • Teks lebih rapat karena line-height: 1.
  • Kotak ketiga menunjukkan alur kerja yang benar: reset dulu, lalu atur ulang sesuai desain sendiri.

3. Isi Reset Eric Meyer

Reset yang paling terkenal dari meyerweb.com (v2.0). Intinya seperti ini (daftar elemennya aslinya jauh lebih panjang): 

html, body, div, span, h1, h2, h3, p, a, ul, li, table, ... {
  margin: 0;
  padding: 0;
  border: 0;
  font-size: 100%;
  font: inherit;
  vertical-align: baseline;
}

body { line-height: 1; }
ol, ul { list-style: none; }
table { border-collapse: collapse; border-spacing: 0; }
AturanEfeknya
margin: 0; padding: 0Semua jarak bawaan dihapus
border: 0Border bawaan dihapus
font: inheritFont mewarisi dari parent, sehingga judul tidak besar/tebal lagi dan strong, em tidak tebal/miring
vertical-align: baselinePerataan vertikal dikembalikan ke normal
line-height: 1 (di body)Jarak antar baris dirapatkan
list-style: noneBullet dan nomor list dihapus
border-collapse: collapseGaris tabel menyatu, tanpa celah

Bagian display: block untuk elemen HTML5 dan aturan quotes di reset aslinya hanya untuk browser lama. Di browser modern tidak diperlukan lagi.

4. Reset Singkat dengan Bintang (*)

* {
  margin: 0;
  padding: 0;
}

Cara paling singkat, tetapi hanya menghapus margin dan padding. Ukuran judul, bullet list, dan strong yang tebal masih bawaan browser.

Soal "tidak disarankan karena berat": itu anggapan lama. Di browser modern, selektor * hampir tidak terasa pengaruhnya pada kecepatan. Alasan yang lebih kuat: ia terlalu kasar karena mengenai semua elemen, termasuk input dan tombol form, dan hanya mereset sebagian gaya bawaan.

5. Reset, Normalize, dan Modern Reset

PendekatanCara kerja
CSS Reset (Meyer)Menghapus hampir semua gaya bawaan, dan kita atur ulang semuanya
Normalize.cssTidak menghapus, hanya menyamakan perbedaan antar browser dan menjaga gaya bawaan yang berguna
Modern resetReset kecil dan sederhana, hanya yang benar-benar sering dibutuhkan

Contoh modern reset sederhana

* {
  box-sizing: border-box;   /* hitungan ukuran lebih mudah */
}

body {
  margin: 0;
  line-height: 1.5;
}

img {
  max-width: 100%;
  height: auto;
}

6. Kesimpulan

  • Browser punya gaya bawaan yang berbeda-beda, dan CSS Reset menyamakannya.
  • Reset ditaruh paling atas di file CSS, sebelum aturan lain.
  • Reset Meyer menghapus margin, padding, border, ukuran dan gaya font, bullet list, dan celah tabel.
  • Setelah reset, kita wajib mengatur ulang ukuran judul, jarak paragraf, dan bullet list sesuai desain.
  • * { margin: 0; padding: 0; } lebih singkat tetapi hanya mereset sebagian.
  • Untuk project kecil, modern reset sederhana biasanya sudah cukup.
