Float

Catatan belajar CSS layouting: mengeluarkan elemen dari alur normal ke kiri atau kanan.

1. Apa itu Float?

float adalah property CSS untuk mengatur posisi elemen. Elemen dipaksa ke sisi kiri atau kanan parent-nya, dan elemen lain (terutama teks) mengalir mengelilinginya.

NilaiArtinya
noneTidak mengambang (default)
leftElemen ke sisi kiri, konten lain mengalir di sebelah kanannya
rightElemen ke sisi kanan, konten lain mengalir di sebelah kirinya

Yang bisa dilakukan dengan float

  • Text wrapping: teks mengelilingi gambar atau elemen lain
  • Image gallery: serangkaian gambar atau kotak berjajar
  • Multi-column layout: halaman dengan beberapa kolom

Sifat float: elemen yang di-float keluar dari alur normal dan otomatis berperilaku seperti block (width dan height berlaku). Margin auto tidak bisa dipakai untuk menengahkannya.

2. Text Wrapping

Gambar di-float, dan teks otomatis mengelilinginya.

float: right

Lorem ipsum dolor sit amet consectetur adipisicing elit. At totam veniam eum consectetur. Sapiente laboriosam ratione saepe ex ipsum aspernatur porro culpa nobis quidem commodi aperiam, vero odit, cupiditate fugiat quos in hic consectetur eaque suscipit tenetur, quod quo repellat.

float: left

Lorem ipsum dolor sit amet consectetur adipisicing elit. At totam veniam eum consectetur. Sapiente laboriosam ratione saepe ex ipsum aspernatur porro culpa nobis quidem commodi aperiam, vero odit, cupiditate fugiat quos in hic consectetur eaque suscipit tenetur, quod quo repellat.

Beri margin pada gambar supaya teks tidak menempel. Pada float: left, margin kanan penting. Pada float: right, margin kiri.

4. Masalah: Parent Menciut

Elemen yang di-float keluar dari alur normal, jadi parent menganggapnya tidak ada. Kalau semua isi parent adalah float, tinggi parent jadi nol dan kotak melewati batas parent (hanya terlihat garis border tipis).

tanpa perbaikan
overflow: auto
display: flow-root

Cara memperbaiki

CaraKeterangan
overflow: auto (atau hidden) pada parentPaling sederhana. Hati-hati: hidden memotong isi yang keluar
display: flow-root pada parentCara modern dan paling bersih, khusus dibuat untuk masalah ini
ClearfixCara klasik: elemen kosong di akhir parent yang diberi clear: both

Clearfix klasik

.clearfix::after {
  content: "";
  display: block;
  clear: both;
}

Di kode latihan awal, masalah ini "diakali" dengan margin: 200px auto supaya ada ruang untuk kotak yang keluar. Itu hanya menutupi gejalanya, bukan memperbaikinya.

5. Clear

clear membuat elemen menolak berdampingan dengan float, sehingga turun ke bawahnya. Nilainya: left, right, both, none.

tanpa clear
Float

Paragraf ini mengalir di sebelah kotak float, karena float tidak menghalangi teks.

clear: both
Float

Paragraf ini turun ke bawah kotak float, karena memakai clear: both.

6. Multi-Column Layout

Tiga kolom dibuat dengan float: left pada semuanya. Lebar kolom dibuat persen dan totalnya 100% agar pas di parent.

Kolom 1 (20%)
Kolom 2 (60%)
Kolom 3 (20%)

Kalau total lebar kolom melebihi lebar parent (misalnya karena padding atau border ikut menambah ukuran pada content-box), kolom terakhir akan turun ke baris bawah. Itu sebabnya box-sizing: border-box sangat membantu.

7. Float, Flex, atau Grid?

Untuk layout halaman, cara modern adalah display: flex dan display: grid. Float aslinya dibuat untuk teks yang mengelilingi gambar, dan itu tetap kegunaan terbaiknya. Float untuk kolom dan galeri masih sering ditemukan di kode lama, jadi penting dipahami.

8. Kesimpulan

  • float punya nilai none, left, right.
  • Elemen float keluar dari alur normal dan teks mengalir mengelilinginya.
  • Float right membalik urutan: elemen pertama berada paling kanan.
  • Parent yang isinya semua float akan menciut. Perbaiki dengan overflow: auto, display: flow-root, atau clearfix.
  • clear membuat elemen turun di bawah float.
  • Float cocok untuk text wrapping. Layout modern memakai flex dan grid.
